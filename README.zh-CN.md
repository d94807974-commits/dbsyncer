# Realtime ETL

Realtime ETL 是一款开源实时数据处理 / ETL 服务，支持 MySQL、Oracle、SQL Server、PostgreSQL、Elasticsearch、Kafka、File、SQL 等同步场景，可通过插件自定义转换逻辑，并监控全量 / 增量同步与告警。

## 构建

```bash
mvn -DskipTests package
```

## 运行

默认管理界面：`http://localhost:18686`（admin / admin）。
