What's a cluster?

In short: form a cluster of multiple DBSyncer nodesHigh Available Sync ServiceI don't know. Single nodes fail and the remaining nodes automatically take over tasks; when the pressure for data synchronization increases, multiple nodes are shared and achieve faster and more stable synchronization capabilities.

Four core strengths:

  • High Performance: Large task automatic split, multi-gaps synchronized, speed multiplied
  • High stability: smart task assignment, abnormal automatic recovery, done without rerun, less process
  • High Available (HA): one machine is dead, the other machines take over immediately, and the synchronized business is guaranteed, and the data is kept on file
  • Dynamic expansion: Business volume increases directly with machine, capacity increases, recommencing without suspension, no additional configuration

Application scenario: Requires simultaneous continuity, large-scale data synchronization. For example, multi-business library sync to silo, TB-level data migration, Incremental simultaneous swallowing 1w+TPS Business.
