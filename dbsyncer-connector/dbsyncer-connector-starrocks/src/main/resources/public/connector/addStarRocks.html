StarRocks connects metadata to JDBC writing through the FE MySQL protocol port (default 9030).

Stream Load uses the FE HTTP port (default 8030) for bulk import; suitable for INSERT/UPDATE/UPSERT. DELETE still uses JDBC.

Currently supports full-time synchronization and time-time increments, and the binlog log increment is not supported; Routine Load needs to create a task on the StarRocks side alone.
